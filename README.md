# Milla House — Family OS

A shared family dashboard for Jon, Amy, and the crew. Hosted with GitHub Pages at **family.millahouse.com**.

## What's on it (v1)

- **Today's Plates** — breakfast, lunch, and dinner from the family's weekly meal rotation, with recipe links
- **This Week's Dinners** — the full Mon–Sun dinner lineup
- **School** — today's A/B schedule day (Davis School District pattern) and the next no-school day
- **Grocery List** — checkable, add your own items (saved in your browser)
- **Family Tasks** — shared to-do list (saved in your browser)

## How updates work

For now, Tom (the family AI assistant) updates the site: new meals, schedule changes, and tweaks go through chat and get deployed here. Grocery and task check-offs save locally in each person's browser.

## Tech

Pure static site — `index.html` + `styles.css` + `app.js`. No build step, no backend. Deployed via GitHub Pages.
